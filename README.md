# MIT mission — тренажёр олимпиадной математики

Веб-приложение для подготовки к Республиканской олимпиаде по математике (RFO), цель — золото в 10 классе.
Работает в браузере без аккаунтов и без ИИ; прогресс хранится в браузере ученика.

## Сайт

https://tony-closeai.github.io/mit-mission/ — GitHub Pages публикует папку `docs/` из ветки `main`.

Как обновить сайт после изменений:

```
python app/build.py
node app/tests/verify-content.js
git -C app add -A
git -C app commit -m "Что изменилось"
git -C app push
```

Через минуту-две новая версия появится по той же ссылке. Прогресс ученика при обновлении сохраняется: он хранится в его браузере.

## Папки

- `src/app.html` — само приложение: оформление и логика (рейтинг, задачи, диагностика, профиль).
- `content/` — содержание: `roadmap.js` (карта тем), `diagnostic.js` (вводная диагностика) и по файлу на тему:
  `divisibility.js` «Делимость и остатки», `alg-expr.js` «Выражения и тождества», `proof.js` «Как доказывать»,
  `tri.js` «Треугольники», `alg-quad.js` «Квадратные уравнения и теорема Виета», `count.js` «Правила подсчёта, перестановки, сочетания», `cong.js` «Сравнения по модулю». `_fig.js` — чертежи:
  `MM.fig({ pts, poly, seg, circ, ang, … })` возвращает SVG; для графиков функций есть `curve` (ломаная по точкам),
  `axes` (оси со стрелками) и `text` (подпись без точки). Координаты можно вычислять прямо в файле темы
  (так сделано в `tri-deep.js` и `alg-quad.js`).
  Глубокий уровень темы лежит в отдельном файле `<тема>-deep.js` (например, `div-deep.js`) и подключается через `MM.addDeep`.
- `build.py` — собирает сайт `docs/` и предпросмотр `dist/mit-mission.html` (одним файлом, всё внутри).
  На сайте темы подгружаются по мере надобности: в `docs/index.html` лежат только ядро (карта, чертежи, диагностика)
  и оглавление тем — названия, условия задач, уровни и рейтинги. Тексты уроков, подсказки, решения и критерии
  каждой темы лежат в `docs/t/<тема>.<хеш>.js` и загружаются при первом открытии урока или задачи.
  Хеш меняется вместе с содержанием, поэтому браузер не возьмёт старую версию из кэша; две прежние версии
  файла остаются на сайте для страниц, открытых до обновления. Оглавление собирает `tools/topic-index.js` —
  для сборки нужен Node.js.
- `docs/` — готовый сайт, его публикует GitHub Pages. Вручную не редактировать: перезаписывается сборкой.
- `tests/verify-content.js` — пересчитывает все ответы и проверяет утверждения в доказательствах.
  Проверки каждой темы лежат в `tests/checks/<тема>.js`, общие функции — в `tests/checks/_lib.js`.
- `ROADMAP.md` — план развития: все темы 1–11 класса и олимпиадные, порядок работы, что готово.
- `tests/smoke.js` — проходит приложение как пользователь (нужен пакет `jsdom`).
- `tests/smoke-goal.js` — проверяет ссылку переноса рейтинга и цели.
- `tests/smoke-plan.js` — проходит план на день как ученик: «Начать», пункт за пунктом, «Дальше по плану»; выходной и длинный день.

## Команды

```
python app/build.py                      # собрать
node app/tests/verify-content.js         # проверить ответы
node app/tests/smoke.js app/docs/index.html        # проверить сайт (после npm i jsdom)
node app/tests/smoke.js app/dist/mit-mission.html   # проверить предпросмотр
node app/tests/smoke-plan.js app/docs/index.html   # проверить план на день
```

## Как добавить тему

1. Создать `content/<тема>.js` по образцу `alg-expr.js`: уроки и задачи пяти уровней. `id` темы должен совпадать с картой в `roadmap.js`.
2. Добавить файл в `CONTENT_FILES` в `build.py`. Сборка сама отнесёт его к теме и положит в `docs/t/`.
3. Создать `tests/checks/<тема>.js` с независимой проверкой каждого ответа и утверждения.
4. Добавить глубокий уровень: `content/<тема>-deep.js` с `MM.addDeep('<тема>', { lessons, problems })` —
   2–3 урока и 12–15 задач уровней 4–5 (что в него входит, сказано в таблице в `ROADMAP.md`), проверки — в `tests/checks/<тема>-deep.js`.
   Файл подключается в `CONTENT_FILES` сразу после файла темы.
5. Собрать, прогнать проверки и автотесты, отметить тему в `ROADMAP.md`, опубликовать.

## Рейтинг

Как в шахматах (Эло): у каждой задачи свой рейтинг, у ученика — свой. Подсказка снижает результат на 20%.
Ступени шкалы: база 1100, районный этап 1350, полуфинал 1650, финал 1850, золото 2050, международный уровень 2300.
Рейтинги задач — экспертная оценка; их стоит уточнять по мере накопления результатов.
