# MIT mission — тренажёр олимпиадной математики

Веб-приложение для подготовки к Республиканской олимпиаде по математике (RFO), цель — золото в 10 классе.
Работает в браузере без аккаунтов и без ИИ; прогресс хранится в браузере ученика.

## Сайт

https://tony-closeai.github.io/mit-mission/ — GitHub Pages публикует папку `docs/` из ветки `main`.

Как обновить сайт после изменений:

```
python app/build.py
node app/tests/verify-content.js
git -C app add -A
git -C app commit -m "Что изменилось"
git -C app push
```

Через минуту-две новая версия появится по той же ссылке. Прогресс ученика при обновлении сохраняется: он хранится в его браузере.

## Папки

- `src/app.html` — само приложение: оформление и логика (рейтинг, задачи, диагностика, профиль).
- `content/` — содержание: `roadmap.js` (карта тем), `diagnostic.js` (вводная диагностика), `divisibility.js` (тема «Делимость и остатки»).
- `build.py` — собирает всё в `docs/index.html` (сайт) и `dist/mit-mission.html` (локальный предпросмотр).
- `docs/` — готовый сайт, его публикует GitHub Pages. Вручную не редактировать: перезаписывается сборкой.
- `tests/verify-content.js` — пересчитывает все ответы перебором и проверяет утверждения в доказательствах.
- `tests/smoke.js` — проходит приложение как пользователь (нужен пакет `jsdom`).

## Команды

```
python app/build.py                      # собрать
node app/tests/verify-content.js         # проверить ответы
node app/tests/smoke.js app/dist/mit-mission.html   # проверить работу (после npm i jsdom)
```

## Как добавить тему

1. Создать `content/<тема>.js` по образцу `divisibility.js`: уроки и задачи пяти уровней.
2. Добавить файл в `CONTENT_FILES` в `build.py` и `id` темы в `roadmap.js`.
3. Добавить проверки ответов в `tests/verify-content.js`, собрать и опубликовать.

## Рейтинг

Как в шахматах (Эло): у каждой задачи свой рейтинг, у ученика — свой. Подсказка снижает результат на 20%.
Ступени шкалы: база 1100, районный этап 1350, полуфинал 1650, финал 1850, золото 2050, международный уровень 2300.
Рейтинги задач — экспертная оценка; их стоит уточнять по мере накопления результатов.
